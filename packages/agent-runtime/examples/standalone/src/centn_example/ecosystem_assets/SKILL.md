# Workshop Metrics Report

Run the fixed `run.py` inside the configured OpenSandbox only. Pass one JSON
argument containing the exact MCP structuredContent, with datasetId and rows.
Each row has label, planned and actual. Do not change source data. The script
creates /artifacts/chart.png and /artifacts/report.json. It accepts no code,
paths, URLs or commands. The host verifies provenance and seals both outputs.
